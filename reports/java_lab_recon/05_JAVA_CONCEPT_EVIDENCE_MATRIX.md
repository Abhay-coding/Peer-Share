## 2. Concepts Investigated But Not Found (`Not present`)

| Concept | Investigation Result | Evidence |
|---|---|---|
| **`enum` types** | Not present | 0 enums in `src/main/java` and `src/test/java` (statuses `"SUCCESS"` / `"FAILED"` are `String` constants/literals). |
| **Abstract classes** | Not present | No `abstract class` authored in `com.peershare.*` (only framework inheritance from `javafx.application.Application` and `javafx.scene.control.Tab`). |
| **`Map` / `HashMap` fields** | Not present directly | `ConcurrentHashMap.newKeySet()` is used in `PeerServer.java` L33 to obtain a `Set<Socket>`, not a `Map`. |
| **`ExecutorService` for client handling** | Not present | `PeerServer` spawns a `new Thread(...)` per accepted client bounded by `Semaphore(10)`; `SocketDeadline` uses `ScheduledThreadPoolExecutor`. |
| **Synchronized blocks** | Not present | Only `synchronized` methods (`PeerServer.start()` and `PeerServer.stop()`). |
| **Runtime polymorphism across custom subtypes** | Not present | No custom polymorphic class hierarchy; polymorphism is via JDK/JavaFX interfaces (`Runnable`, `AutoCloseable`, `BooleanSupplier`, `Callable`, `Consumer`, `Function`) and `SocketRequest<T>`. |
| **Singleton pattern** | Not present | `AppLogger.create()` wraps `Logger.getLogger("com.peershare")` (JDK logger registry), and `SocketDeadline.TIMER` is a `private static final` timer; no `getInstance()` singleton class exists. |
| **Serialization (`Serializable`)** | Not present | Custom UTF-8 text + raw binary protocol is used instead of Java Object Serialization. |
| **FXML / SceneBuilder** | Not present | All JavaFX UI is constructed programmatically in Java + `peershare.css`. |
